# Artem Illiushchenko - Portfolio

Single-page portfolio website built with React + TypeScript + Vite and CSS Modules.

## Sections

- Hero - name, role, photo
- About - short summary
- Projects - Leleka (Pregnancy Tracker App) and Retail (Rental Car App)
- Skills - hard skills, soft skills, languages
- Education
- Contacts

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site is deployed to GitHub Pages automatically by the workflow in `.github/workflows/deploy.yml` on every push to `main`.
